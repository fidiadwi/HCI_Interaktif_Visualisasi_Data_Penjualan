# Dasbor Interaktif Analisis Penjualan

Proyek Webinar 5: Human-Computer Interaction & Data Visualization.

Dasbor interaktif untuk menganalisis data penjualan, dibuat dengan Python di Google Colab
menggunakan Pandas, Plotly, Matplotlib, dan ipywidgets.

## Dataset

[Online Retail](https://archive.ics.uci.edu/dataset/352/online+retail) dari UCI Machine Learning Repository.
Dataset diunduh otomatis oleh notebook.

## Fitur

- Empat kartu KPI: total penjualan, transaksi, jumlah unit, dan jenis produk
- Grafik garis tren penjualan bulanan
- Grafik batang produk dengan penjualan tertinggi
- Tabel ringkasan produk
- Filter negara dan jumlah produk

## Cara Menjalankan

1. Buka `Proyek5_Interaktif_Visualisasi_Data_Penjualan.ipynb` di Google Colab.
2. Pilih **Runtime > Restart session and run all**.
3. Dasbor interaktif muncul pada Cell 11.
